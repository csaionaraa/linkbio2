## 🚀 Como Usar (16 Minutos)

### Passo 1: Google Sheets (10 min)
1. Acesse sheets.google.com
2. Crie planilha "Roleta Premiada"
3. Adicione colunas: Nome, Sobrenome, Email, Telefone, Prêmio, Data
4. Vá em Extensões → Apps Script
5. Copie código de `APPS_SCRIPT.gs`
6. Implante (Tipo: Aplicação Web, Acesso: Qualquer pessoa)
7. Copie URL fornecida

### Passo 2: Configurar URL (1 min)
1. Abra `src/Roleta.jsx`
2. Linha 4: Substitua `YOUR_SCRIPT_ID` pela URL completa
3. Salve

### Passo 3: Testar (5 min)
1. Acesse http://localhost:5173/roleta
2. Clique botão → Preencha formulário → Veja girar
3. Verifique dados no Google Sheets

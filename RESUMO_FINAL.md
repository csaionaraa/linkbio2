### Passo 1: Setup Google Sheets (10 min)
1. Criar planilha em sheets.google.com
2. Adicionar colunas: Nome, Sobrenome, Email, Telefone, Prêmio, Data
3. Criar Apps Script (copiar de `APPS_SCRIPT.gs`)
4. Implantar e copiar URL

### Passo 2: Configurar URL (1 min)
1. Abrir `src/Roleta.jsx`
2. Linha 10: Substituir URL
3. Salvar arquivo

### Passo 3: Testar (5 min)
1. Acessar `/roleta`
2. Preencher formulário
3. Ver roleta girar
4. Verificar dados no Google Sheets
